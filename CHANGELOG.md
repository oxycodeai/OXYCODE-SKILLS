# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-24

### Added

#### Skills
- **ui-builder** - Generate production-ready UI components and pages from text prompts
  - React/TypeScript output with Tailwind CSS
  - Responsive design support
  - Accessibility attributes
  - Design token integration
  - No AI slop patterns
  
- **design-md** - Generate and validate DESIGN.md files
  - DESIGN.md generation from project requirements
  - Validation script for existing DESIGN.md files
  - Tailwind CSS config conversion
  - Google's open-source design system standard

#### Documentation
- README.md with installation and usage instructions
- Quick start guide
- Contributing guidelines
- Changelog

#### Examples
- Landing page example with hero, features, pricing, testimonials
- Dashboard example with sidebar, stats cards, data table
- Good vs bad DESIGN.md examples

#### References
- Component patterns reference
- Layout system reference
- Polish checklist
- DESIGN.md specification

### Security
- MIT License
- No secrets or credentials in repository
